# La Carrera Monstruosa

Runner local de obstáculos. Elige una criatura frente a una mansión nocturna, corre por tres carriles y supera tu récord. No necesita instalación, servidor ni conexión a Internet.

## Jugar

Abre `index.html` en el navegador.

## Controles

- Flechas izquierda/derecha o A/D: cambiar de carril.
- W, Espacio o flecha arriba: saltar.
- F o X: activar la habilidad del personaje.
- P o Escape: pausar y reanudar.
- En móvil: deslizar para cambiar de carril y usar los botones táctiles para saltar y activar el poder.

## Obstáculos

- **Castillo:** armaduras vacías y bloques de piedra grandes, además de huecos en el suelo.
- **Bosque:** raíces que sobresalen, troncos caídos y huecos.
- **Cementerio:** lápidas, rejas puntiagudas y fosas abiertas.

La pista tiene tres carriles en perspectiva. Armaduras, bloques, lápidas y rejas se esquivan cambiando de carril; raíces, troncos y huecos se pueden saltar. Los obstáculos aparecen desde la entrada del camino y aumentan de tamaño al acercarse.

La habilidad de vuelo de la bruja permite pasar sobre raíces, troncos y huecos, pero no sobre objetos sólidos como armaduras, bloques, lápidas o rejas.

## Récords

Se guardan en el navegador de este equipo, tanto el récord global como el de cada personaje. Si el navegador bloquea el almacenamiento para archivos locales, el juego mantiene el récord durante la sesión y lo indica.

## Pruebas

Abre `tests.html`; no requiere herramientas adicionales.
